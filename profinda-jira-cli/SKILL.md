# ProFinda Jira Tooling

Agents use the `mcp-atlassian` MCP server for all Jira operations. See [MCP.md](MCP.md) for tool reference, common patterns, and setup.

Developers who want to use `jira-cli` directly from the terminal (outside of an agent session) can find the CLI reference and field option IDs in [REFERENCE.md](REFERENCE.md).
